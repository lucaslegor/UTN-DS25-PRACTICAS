Capítulo 4: Ingenieria de requerimientos

4.1 Tipos de Requisitos

Los requisitos de software pueden clasificarse en diferentes categorías:

  • Requisitos Funcionales: Describen las funciones que el sistema debe realizar
  • Requisitos No Funcionales: Son limitaciones sobre servicios o funciones que ofrece el sistema

4.2 El documento de requerimientos de software

El documento de requerimientos de software incluye las siguientes cosas:

  • Estudio de viabilidad
  • Obtención y análisis de requisitos
  • Especificación de requisitos
  • Validación de requisitos

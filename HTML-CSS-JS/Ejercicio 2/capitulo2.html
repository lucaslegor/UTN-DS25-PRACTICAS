Capítulo 2: Procesos de Software

2.1 Modelos de Proceso de Software

Los modelos de proceso de software son representaciones abstractas de un proceso de software. Cada modelo representa un proceso desde una perspectiva particular. Los modelos más comunes incluyen:

  • Modelo en Cascada
  • Desarrollo Incremental
  • Desarrollo Iterativo
  • Metodologías Ágiles

2.2 Actividades del Proceso

Las actividades fundamentales que son comunes a todos los procesos de software son:

  • Especificación de requisitos
  • Diseño e implementación
  • Validación
  • Evolución

2.3 Como Enfrentar el Cambio

  • Crear un Prototipo
  • Entregas Incrementales
  • Volver al Índice
